# 可靠性测试工程师学习系统

> 3 个月系统学习计划配套习题网站 · 280+ 精选习题 · 离线可用

## 🎯 功能特性

- ✅ **12 周完整题库**：按学习计划分周组织，循序渐进
- ✅ **四种题型**：单选、多选、填空、判断
- ✅ **实时判分**：提交即出分，答案解析详尽
- ✅ **错题本**：自动收集错题，方便复习
- ✅ **进度跟踪**：本地保存学习数据
- ✅ **模拟考试**：30 题随机抽题，检验综合能力
- ✅ **响应式设计**：手机/电脑/平板均可使用
- ✅ **离线可用**：纯静态，无需服务器

## 🚀 使用方法

### 方式 1：直接打开（推荐）

双击 `index.html`，浏览器自动打开即可使用。

### 方式 2：本地服务器（如需扩展功能）

```bash
# Python 3
cd ReliabilityStudy
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

```bash
# Node.js
npx serve
```

## 🎓 学习建议

1. **按周学习**：从第 1 周开始，每天 1-2 套题
2. **错题必看**：每道题解析都包含考点
3. **周末复习**：用"模拟考试"检验本周学习
4. **错题本复习**：定期回顾错题本
